Privacy Policy

This policy describes how MJPDF handles information when you use the website and PDF tools.

Information we process

When you use a tool, you upload a file that is sent to the server for processing. We may also receive basic technical data such as browser type and IP address via normal web server logs.

How files are handled

Uploaded files are stored temporarily so the selected tool can run. Processed output files are generated so you can download them. Temporary and output files are subject to automatic cleanup on the server (typically within about one hour, subject to server configuration and maintenance).

MJPDF is not designed as long-term file storage. Do not rely on us to keep your documents after you leave the page.

Cookies and analytics

The core tools do not require an account. If cookies or analytics are added later, this page will be updated to describe them.

Security

We take reasonable measures to process files safely, including size limits and temporary storage. No online service can guarantee absolute security; avoid uploading highly sensitive material when possible.
