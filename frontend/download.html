Step-by-step: run on your PC

1) Download and unzip

  1. Click Open in Google Drive above, then Download the ZIP.
  2. Extract the ZIP to a folder, for example Desktop/mjpdf.
  3. Open a terminal inside that folder.

2) Install Python

Windows: https://www.python.org/downloads/ — enable Add Python to PATH.

macOS: brew install python or python.org installer.

Linux: sudo apt install python3 python3-pip python3-venv

3) Install LibreOffice

Windows / macOS: https://www.libreoffice.org/download/download/

Linux: sudo apt install libreoffice

Without LibreOffice, Word → PDF and PowerPoint → PDF will fail. Other tools (merge, compress, rotate, etc.) still work.

4) Create virtual environment and install packages

Windows (PowerShell):

cd path\to\mjpdf python -m venv venv .\venv\Scripts\Activate.ps1 pip install -r backend\requirements.txt

macOS / Linux:

cd path/to/mjpdf python3 -m venv venv source venv/bin/activate pip install -r backend/requirements.txt

5) Start the server

Windows:

.\venv\Scripts\Activate.ps1 $env:PYTHONPATH = $PWD uvicorn backend.app.main:app --host 0.0.0.0 --port 8000

macOS / Linux:

source venv/bin/activate export PYTHONPATH=$PWD uvicorn backend.app.main:app --host 0.0.0.0 --port 8000

6) Open in browser

Go to http://localhost:8000

Stop the server with Ctrl + C.

Optional software

  • Ghostscript — better Compress PDF: https://ghostscript.com/releases/gsdnld.html
  • Docker — if you deploy with the included Dockerfile (e.g. on Render)

Common problems

  • uvicorn not found — activate venv and run pip install -r backend/requirements.txt again.
  • Word to PDF error / WinError 2 — install LibreOffice and restart the terminal.
  • PowerShell blocks Activate.ps1 — run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  • Old UI — hard refresh: Ctrl+F5

Tech stack (short)

Python, FastAPI, Uvicorn, PyMuPDF, pypdf, pdf2docx, LibreOffice, HTML/CSS/JavaScript.
