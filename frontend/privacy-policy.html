Privacy Policy

This policy explains how MJPDF handles information when you use the website and PDF tools.

Introduction

MJPDF provides online document tools. Using a tool typically requires uploading a file for processing and downloading a result.

Information we collect

When you process a file, the file content is sent to the server. Standard technical data (such as IP address, browser type, and request logs) may also be recorded by the hosting environment.

Uploaded files

Uploaded files are stored temporarily so the selected tool can run. Output files are generated so you can download them. MJPDF is not a long-term storage service.

How we use information

Files and related request data are used to perform the tool you requested, operate the service, and maintain security and reliability.

File processing

Processing happens on the server using the selected tool. Results are returned for download through the website interface.

Data retention

Temporary upload and output files are subject to automatic cleanup on the server. In the current implementation, older temporary and output files are cleaned up on a periodic basis (on the order of about one hour, subject to server configuration and maintenance). Do not rely on MJPDF to retain documents after you leave the page.

Cookies

Essential cookies or local storage may be used to remember cookie preferences. See the Cookie Policy for details.

Third-party services

The core tools run on the MJPDF application server. If additional third-party services are introduced later, this policy will be updated.

Security

Reasonable measures are used to process files safely, including size limits and temporary storage practices. No online service can guarantee absolute security.

User rights

Depending on your location, you may have rights regarding personal data. Contact us with privacy requests.

Children’s privacy

MJPDF is not directed at children under 13, and we do not knowingly collect personal information from children.

Changes

We may update this policy from time to time. Continued use of the site after changes means you accept the updated policy.
